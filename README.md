# MoneyLog para Linux (apt)

Repositorio apt de [MoneyLog](https://getmoneylog.com) para Ubuntu y Debian (amd64).

```sh
curl -fsSL https://novasofttechnologiescorp.github.io/moneylog-apt/instalar.sh | sudo sh
sudo apt install moneylog
```

Las actualizaciones llegan con `sudo apt upgrade`. Lo publica el workflow `linux-deb` del repo de la app; no se edita a mano.
